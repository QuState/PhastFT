Single-thread four-pass FFT transpose comparison: 64 MiB and 2 GiB

Date: 2026-10-21
CPU: AMD Ryzen 9 9950X
Threads: RAYON_NUM_THREADS=1; all benchmark processes pinned to CPU 2 with taskset.
Build: unchanged release executable from the previous SIMD transpose experiments.
No new code, compiler flags or matrix/tile tuning.
Binary SHA-256: 5b27454c9c9950db6e98bab8cd639663b8e39ea08050687b1354fd9bf926dcb5

Input sizes count both real and imaginary arrays; scratch requires the same
number of bytes again, plus small plans and worker-local temporary storage.
64 MiB: f64 2^22 points, 512 x 8192; f32 2^23 points, 512 x 16384.
2 GiB: f64 2^27 points, 2048 x 65536; f32 2^28 points, 4096 x 65536.

Method:
- Same executable and existing layout for every transpose variant.
- Scalar packed, SIMD packed and SIMD direct selected with FOUR_PASS_TRANSPOSE.
- One Rayon worker; internal local FFT parallelism is disabled by the prototype.
- Three blocks of 30 transforms at 64 MiB (90 samples per variant/precision).
- Three blocks of 5 transforms at 2 GiB (15 samples per variant/precision).
- Rotate process order: scalar/simd/direct, simd/direct/scalar, direct/scalar/simd.
- Run f64 then f32 at 64 MiB, followed by f64 then f32 at 2 GiB.
- Each process has one excluded warm-up. Identical seeded input regenerated
  before each transform; allocation, planning and input generation are untimed.
- Scratch pages touched before timing. FOUR_PASS_PROFILE unset.
- Runs sequential, without concurrent compilation or tests.
- All SIMD runs report the Avx512 backend, using the previously disassembled binary.
- Separate both-mode checks at both sizes/precisions for all variants compare
  4096 output bins with DIT. Those timing samples are excluded from the results.
- The existing parallel build is restricted to one worker, not rebuilt without
  Rayon. CPU affinity also confines the calling thread to the same CPU.
